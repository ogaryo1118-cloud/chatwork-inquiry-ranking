# 役員報酬比較シミュレーター（Python / Streamlit版）

役員報酬の複数案について、本人負担・手取り・会社負担・会社総コストを比較するPoCです。

公開URL: https://yakuin-hoshu-simulator.streamlit.app/

## 対応範囲

- 東京都・協会けんぽ
- 令和8年4月分以降
- 源泉所得税：令和8年分・月額表・甲欄・扶養0人
- 年齢：20〜74歳
- 70〜74歳は通常の厚生年金保険料を0円として計算（高齢任意加入は考慮しません）
- 75歳以上は後期高齢者医療制度となるため本PoCの対象外

## 令和8年度の主な前提

- 健康保険料率（東京）：9.85%
- 介護保険料率：1.62%（40〜64歳）
- 厚生年金保険料率：18.3%
- 子ども・子育て支援金率：0.23%（被保険者と事業主が原則折半）
- 子ども・子育て拠出金率：0.36%（会社負担のみ）

健康保険と厚生年金は標準報酬月額の下限・上限が異なるため、別々に判定します。たとえば報酬月額8万円の場合、健康保険の標準報酬月額は78,000円、厚生年金は最低等級の88,000円です。

給与から被保険者負担分を控除する場合、円未満が50銭以下なら切捨て、50銭を超える場合は切上げる端数処理を反映しています。

会社負担額は1名分の概算です。実際の納入告知額は事業所全体で合算後に端数処理されるため、数円の差が生じる場合があります。

## ローカル起動

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## テスト

```bash
python test_calc.py
```

基準ケース（39歳、80,000円 / 100,000円 / 150,000円）と70歳ケースを回帰テストしています。

## データ構成

- `app.py` … Streamlit画面
- `calc.py` … 計算ロジック
- `master_standard_remuneration.csv` … 健康保険・厚生年金の標準報酬月額マスタ
- `master_rates.csv` … 保険料率マスタ
- `master_tax_table_low.csv` … 源泉徴収税額表（甲欄・扶養0人）
- `test_calc.py` … 回帰テスト

## 主な公式資料

- 全国健康保険協会「令和8年度 保険料額表（東京支部）」
- 日本年金機構「厚生年金保険料額表」
- こども家庭庁「子ども・子育て支援金制度」
- 国税庁「令和8年分 源泉徴収税額表」
